# Lab-11-ML

This project focuses on analyzing credit card customer behavior using the K-Means clustering algorithm. The dataset contains information about approximately 8,950 customers, including their balance, purchases, cash advance usage, credit limits, and payment patterns. These features provide a clear view of how customers interact with their credit cards and allow deeper analysis of their financial behavior.

K-Means is an unsupervised machine learning algorithm used to group similar data points into clusters based on their features. In this project, the algorithm was applied after preprocessing the data, including handling missing values and scaling the features to ensure fair comparison between variables. Dimensionality reduction using PCA was also used to simplify the data and improve visualization.

To determine the optimal number of clusters, both the Elbow Method and Silhouette Score were used. Based on the analysis, the number of clusters was selected to provide a balance between mathematical accuracy and meaningful interpretation of customer groups.

The results of this project show that customers can be divided into different segments such as high-value users, low-activity customers, and those with high cash advance usage. These insights can help businesses better understand customer behavior, improve marketing strategies, and manage financial risks more effectively. Overall, this project demonstrates how machine learning techniques can be used to extract useful patterns from real-world financial data.
