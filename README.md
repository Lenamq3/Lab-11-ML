# Lab-11-ML

This dataset contains information about credit card customers and their financial behavior. It includes approximately 8,950 records with multiple features that describe how customers use their credit cards, such as their account balance, purchase activity, cash advance usage, credit limits, and payment patterns. The dataset also reflects how frequently customers make purchases, whether they rely on installment payments, and how long they have been using their accounts. These features make it possible to better understand customer behavior and identify different spending habits. The dataset is commonly used in data analysis and machine learning tasks, especially for customer segmentation and clustering. It can help in analyzing spending behavior, identifying valuable or risky customers, and supporting decision-making through data-driven insights. Overall, it is suitable for both beginner and intermediate-level projects in data science.
